# প্রশ্ন ব্যাংক তারিখ নম্বর শতকরা অ্যাকশন

ব্যাকআপ ও ডেটা রিস্টোর

আপনার সমস্ত প্রশ্ন ব্যাংক, বুকমার্ক ও পরীক্ষার ইতিহাস এক্সপোর্ট অথবা ইমপোর্ট করুন

সম্পূর্ণ ব্যাকআপ এক্সপোর্ট (JSON)

আপনার সংরক্ষিত সকল প্রশ্ন ব্যাংক, বুকমার্ক, অনুশীলিত ইতিহাস ও পরিসংখ্যান একটি পোর্টেবল JSON ফাইলে ডাউনলোড করুন।

ব্যাকআপ ফাইল থেকে রিস্টোর (JSON Import)

পূর্বে এক্সপোর্ট করা কোনো ব্যাকআপ JSON ফাইল সিলেক্ট করুন। ফাইল যাচাই করে সংযুক্ত (Merge) বা প্রতিস্থাপন (Replace) করতে পারবেন।
